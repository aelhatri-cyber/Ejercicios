# T03 — Ejercicios de clase: Tecnologías Habilitadoras Digitales (THD)
## EC3.1 Identifica las 9 THD (básico)

Relaciona cada acrónimo o tecnología con su nombre completo.

| Nº | Acrónimo / tecnología | Respuesta |
| --- | --- | --- |
| 1 | IoT | Internet de las Cosas (Internet of Things). |
| 2 | Big Data | Grandes volúmenes de datos que se analizan para obtener información útil. |
| 3 | IA | Inteligencia Artificial. |
| 4 | Cloud | Computación en la nube (Cloud Computing). |
| 5 | Ciberseguridad | Tecnologías y medidas para proteger sistemas, redes y datos frente a ataques. |
| 6 | Blockchain | Cadena de bloques: tecnología de registro digital distribuido e inmutable. |
| 7 | RPA | Automatización Robótica de Procesos (Robotic Process Automation). |

| 9 | AR/VR | Realidad Aumentada (AR) y Realidad Virtual (VR). |

## EC3.3 ¿Qué THD resuelve qué problema de negocio? (básico)

| Problema de negocio | THD propuesta | Justificación |
| --- | --- | --- |
| Tenemos millones de logs pero no sacamos conclusiones operativas. | Big Data | Permite procesar grandes cantidades de registros, identificar patrones y obtener información útil para tomar decisiones. |
| El soporte técnico pierde demasiadas horas en preguntas repetitivas. | IA | Un chatbot puede responder automáticamente las preguntas frecuentes y reducir la carga de trabajo del personal. |
| Debemos garantizar que un certificado digital que emitimos no se falsifique. | Blockchain | Permite registrar certificados de forma segura, verificable y difícil de modificar o falsificar. |
| Queremos ofrecer un producto sin invertir en CPD propio. | Cloud | Permite alojar aplicaciones y almacenar datos en servidores externos pagando por los recursos utilizados. |
| Queremos analizar imágenes de productos para detectar defectos visuales. | IA | Mediante visión artificial puede analizar imágenes e identificar defectos automáticamente. |
| Queremos simular entornos industriales para formar personal técnico. | AR/VR | Permite crear simulaciones virtuales e inmersivas para practicar sin riesgos ni necesidad de utilizar maquinaria real. |

## EC3.4 THD y sostenibilidad (medio)

Elige tres THD y explica cómo contribuyen a la sostenibilidad en una empresa TIC.

| THD | Cómo contribuye a la sostenibilidad | Ejemplo concreto en una empresa TIC |
| --- | --- | --- |
| IoT | Reduce el consumo energético mediante sensores que controlan los recursos en tiempo real. | Una empresa instala sensores en sus oficinas para apagar automáticamente la iluminación y el aire acondicionado cuando no hay personas. |
| Cloud | Permite utilizar centros de datos optimizados y compartir recursos informáticos, evitando mantener servidores propios infrautilizados. | Una empresa migra sus aplicaciones a la nube y elimina servidores antiguos que consumían electricidad continuamente. |
| Big Data | Permite analizar datos para detectar desperdicios, mejorar procesos y reducir el consumo de recursos. | Una empresa analiza los datos de consumo eléctrico de sus equipos para identificar los ordenadores y servidores que gastan demasiada energía. |

## EC3.6 Parte de negocio vs. parte de planta (medio)

Marca dónde puede tener impacto cada THD.

| THD | Negocio | Planta | Ambas |
| --- | --- | --- | --- |
| IoT |  |  | X |
| Big Data |  |  | X |
| IA |  |  | X |
| Cloud | X |  |  |
| Ciberseguridad |  |  | X |
| Blockchain | X |  |  |
| RPA | X |  |  |
| Fabricación aditiva |  | X |  |
| AR/VR |  |  | X |

Justificación:

- IoT: conecta sensores de producción y dispositivos de negocio.
- Big Data: analiza datos comerciales y datos de producción.
- IA: permite automatizar decisiones administrativas y controlar procesos industriales.
- Cloud: facilita principalmente la gestión empresarial y el almacenamiento de información.
- Ciberseguridad: protege tanto los sistemas informáticos de oficina como los sistemas industriales.
- Blockchain: puede utilizarse para contratos, facturas y trazabilidad de productos.
- RPA: automatiza tareas administrativas y comerciales.
- Fabricación aditiva: se utiliza principalmente en la producción de piezas y prototipos.
- AR/VR: sirve tanto para formación empresarial como para asistencia y mantenimiento industrial.

Nota: algunas tecnologías pueden utilizarse en más de una zona dependiendo de la empresa.

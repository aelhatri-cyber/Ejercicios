# T03 — Ejercicios de clase: Tecnologías Habilitadoras Digitales (THD)
## EC3.1 Identifica las 9 THD (básico)

Relaciona cada acrónimo o tecnología con su nombre completo.

| Nº | Acrónimo / tecnología | Respuesta |
| --- | --- | --- |
| 1 | IoT | Internet de las Cosas (Internet of Things). |
| 2 | Big Data | Grandes volúmenes de datos que se analizan para obtener información útil. |
| 3 | IA | Inteligencia Artificial. |
| 4 | Cloud | Computación en la nube (Cloud Computing). |
| 5 | Ciberseguridad | Tecnologías y medidas para proteger sistemas, redes y datos frente a ataques. |
| 6 | Blockchain | Cadena de bloques: tecnología de registro digital distribuido e inmutable. |
| 7 | RPA | Automatización Robótica de Procesos (Robotic Process Automation). |
| 8 | Fabricación aditiva | Fabricación de objetos mediante impresión 3D, añadiendo material capa a capa. |
| 9 | AR/VR | Realidad Aumentada (AR) y Realidad Virtual (VR). |

## EC3.2 Quién es quién (básico)

Une cada situación con la THD correspondiente.

| Nº | Situación | THD correspondiente |
| --- | --- | --- |
| 1 | Un script lee correos, descarga PDFs y extrae datos para rellenar un ERP. | RPA |
| 2 | Tres empresas comparten un registro de certificados académicos sin confiar en una autoridad central. | Blockchain |
| 3 | Una consultora audita aplicaciones web y hace pruebas de penetración. | Ciberseguridad |
| 4 | Una startup lanza su producto sin comprar servidores propios. | Cloud |
| 5 | Un almacén imprime la pieza exacta de una máquina cuando esta se rompe. | Fabricación aditiva |
| 6 | Una consultora forma equipos de ciberseguridad en simulaciones inmersivas. | AR/VR |
| 7 | Un sistema de analítica de logs detecta patrones de ataque en millones de eventos por segundo. | Big Data |
| 8 | Sensores en una planta envían datos de temperatura a una plataforma en la nube. | IoT |
| 9 | Un asistente virtual resuelve dudas frecuentes de una app. | IA |
